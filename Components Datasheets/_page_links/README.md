# Page links

Word cannot open a local PDF at a given page: it drops the `#page=N` part of a hyperlink.
The TC documents therefore link to these small HTML pages instead. Each one opens in the
default browser and redirects straight to the PDF at the right page
(e.g. `MAX96714_p073.html` → `../Deserializer/deserializer_max96714.pdf#page=73`).

Keep this folder next to the datasheet folders, so the relative links keep working.
